void pcod_common::ApplyRotatedNms ( std::vector< BoundingBox > & bboxes,
const NmsConfig & config,
NmsStats * stats )

Filter and reorder boxes in place. Merging retains the strongest representative's geometry, score, existence and velocity. Full class distributions are averaged using detection scores as weights (uniform if all are zero). Classification scores remain logits: merged distributions are stored as log probabilities. Membership and ordinary NMS use the original representative, preventing transitive merging and changes in suppression caused by a fused winning class. Candidates are consumed past the output limit when merging is enabled, so late members can still contribute. Boxes without positive heights can be suppressed in BEV, but are never merged.

Parameters
bboxesBoxes to process.
configSuppression and merging configuration.
statsOptional operation counts.
Exceptions
std::invalid_argumentIf merging is enabled with an invalid threshold or class logits.
